# 🔤 Подбери звуковую схему к слову

Интерактивная развивающая игра для детей старшего дошкольного возраста (5–7 лет), направленная на развитие фонематического слуха, навыков звукового анализа слов и подготовку к обучению грамоте.

👉 **[Открыть и играть в браузере](https://irina-krainskaya.github.io/igra4/)**

---

### 🎯 О чём эта игра?
Ребёнку предлагается соотнести слова с их цветовыми звуковыми схемами. На экране представлены карточки с иллюстрациями и словами (всего 27 слов), для каждого из которых нужно подобрать подходящую последовательность звуковых обозначений.

### ✨ Особенности тренажёра:
* **Наглядный звуковой анализ:** карточки со звуками обозначены традиционными цветами (красный — гласные, синий — твёрдые согласные, зелёный — мягкие согласные), что помогает ребёнку визуально различать звуки в слове.
* **Удобное управление:** выбрать нужную звуковую карточку можно простым кликом или перетаскиванием в пустое окошко под словом.
* **Подсказки и самоконтроль:**
  * Счётчик **«Собрано: 0 из 27»** позволяет отслеживать прогресс выполнения задания.
  * Кнопка **«Памятка цветов»** помогает ребёнку вспомнить, какой цвет какому звуку соответствует.
  * Кнопка **«Перемешать»** меняет порядок слов и карточек для повторного закрепления материала.
